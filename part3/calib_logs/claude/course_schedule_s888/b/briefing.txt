# BRIEFING: Course Schedule - Cycle Detection

**GOAL:**
Determine if all courses can be completed given prerequisite constraints. Return `True` if no circular dependencies exist, `False` if a cycle prevents completion.

**STATE:**
- Implementation uses Kahn's algorithm (topological sort via BFS with in-degree tracking)
- Graph represented as adjacency list + in-degree array
- Algorithm processes courses with no prerequisites first, decrementing dependent courses' in-degrees
- Final check: if `completed == numCourses`, all courses are finishable (no cycle)
