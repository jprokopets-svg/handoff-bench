**GOAL:**
Implement a complete Trie (prefix tree) data structure supporting word insertion, exact-match search, and prefix matching.

**STATE:**
- `TrieNode` class: stores children dict and end-of-word flag
- `Trie` class with three methods: `insert()`, `search()`, `starts_with()`
- All unit tests currently passing

**DONE:**

✓ Word insertion with automatic node creation

✓ Test suite passes

**BROKEN:**
- No known functional issues in core methods
- Potential gaps (not yet tested):
  - Delete/remove word functionality (not implemented)
  - Case sensitivity handling (unclear if required)
  - Empty string edge cases
  - Performance with large datasets
  - Memory efficiency considerations
  - No docstring for `TrieNode`

**NEXT:**
Implement a `delete(word)` method that:
1. Searches for the word in the trie
2. If found, marks `is_end_of_word = False`
3. Recursively removes nodes with no children and `is_end_of_word = False` (cleanup)
4. Returns True if deletion succeeded, False if word not found

This is the most common missing feature in trie implementations and likely needed for production use.
