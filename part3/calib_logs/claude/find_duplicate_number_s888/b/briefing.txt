# BRIEFING: find_duplicate_number.py

**GOAL:**
Implement an algorithm to find the duplicate number in an array of n+1 integers where each integer is in range [1, n] and exactly one number appears more than once. Solution must work correctly and efficiently.

**STATE:**
- Implementation complete using Floyd's Cycle Detection algorithm (tortoise and hare)
- Algorithm treats the array as a linked list where `nums[i]` points to index `nums[i]`
- Two-phase approach:
  - Phase 1: Detect cycle by moving slow pointer 1 step and fast pointer 2 steps until they meet
  - Phase 2: Find cycle entrance (the duplicate) by moving both pointers 1 step at a time from meeting point and array start
