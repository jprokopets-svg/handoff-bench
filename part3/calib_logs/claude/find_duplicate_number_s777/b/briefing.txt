# BRIEFING: find_duplicate_number.py

**GOAL:**
Implement an algorithm to find the single duplicate number in an array of n+1 integers where each integer is in range [1, n]. Must handle the constraint efficiently.

**STATE:**
- Implementation complete using Floyd's Cycle Detection algorithm (tortoise and hare)
- Algorithm treats array as a linked list where `nums[i]` points to index `nums[i]`
- Two-phase approach:
  - Phase 1: Detect cycle by moving slow pointer 1 step, fast pointer 2 steps until collision
  - Phase 2: Find cycle entrance by moving both pointers 1 step from collision point and nums[0]
