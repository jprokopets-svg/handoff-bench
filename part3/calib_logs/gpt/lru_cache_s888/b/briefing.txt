STATE: lru_cache.py contains a doubly-linked list + dict LRUCache implementation with Node class and methods: _add_node, _remove_node, _move_to_front, _pop_tail, get, put. Constructor enforces capacity > 0. Dummy head/tail sentinels used. All provided tests currently pass.

DONE:

- _add_node/_remove_node correctly maintain pointers and clear removed node pointers.
