**GOAL:** Convert GitHub-flavored markdown tables to strict HTML with proper alignment support.

**STATE:** 
- Complete implementation of `md_table_to_html()` function with helper functions

- Supports optional leading/trailing pipes and escaped pipes (`\|`)
- Alignment parsing: `:---` (left), `---:` (right), `:---:` (center)
- HTML escaping for `&`, `<`, `>`
