## BROKEN
**Critical: Star (*) quantifier backtracking is broken**

Test case failing: `full_match('a*ab', 'aaab')` returns False but should return True

**Root cause:** The `Star.match()` method has a logic error:
```python
for try_pos in reversed(positions):
    yield_pos = try_pos
    return yield_pos
return -1
```

This loop immediately returns the first (longest) position without actually attempting to match the rest of the pattern. It doesn't integrate with the parent `Concatenation` to try shorter matches on backtracking.
