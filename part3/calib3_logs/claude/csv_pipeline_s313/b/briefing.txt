# BRIEFING: CSV Pipeline Handoff

**GOAL:**
Implement a CSV parser and transformer that:
1. Parses RFC-4180 compliant CSV (handles quoted fields, escaped quotes, multiline fields)
2. Filters out rows where `status` column equals `'skip'`
3. Sorts by `sort` column (numeric values first, then lexicographic)
4. Re-serializes to CSV with trailing newline

**STATE:**
Complete implementation exists with four functions:
- `process_csv()` - main orchestrator
- `_parse_csv()` - RFC-4180 parser with quote/escape handling
- `_sort_rows()` - custom sort with numeric-first logic
- `_format_csv()` + `_quote_field()` - serialization with proper escaping

All unit tests passing.
