# BRIEFING: graph_serializer.py

## GOAL
Implement a bidirectional serializer that converts Python objects to/from JSON strings while preserving:
- Shared references (same object referenced multiple times)
- Cycles (objects containing references to themselves)

## STATE
- Complete implementation of `encode()` and `decode()` functions
- Encoder assigns unique IDs to container objects (lists/dicts)
- Decoder reconstructs objects with shared references and cycles intact
- All tests passing

## DONE
