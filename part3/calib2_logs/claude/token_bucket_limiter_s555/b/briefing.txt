# BRIEFING: Token Bucket Limiter

**GOAL:**
Implement a token bucket rate limiter that controls request throughput by managing token consumption. Tokens refill over time at a configurable rate. Requests are allowed only if sufficient tokens are available.

**STATE:**
- `TokenBucket` class fully implemented with:
  - Constructor accepting `capacity` and `refill_rate` parameters
  - `allow()` method that checks token availability and consumes tokens
  - Time-based refill logic using `time.monotonic()` for precision
  - Support for deterministic testing via optional `now` parameter
  - Lazy initialization of `last_refill_time` on first call
